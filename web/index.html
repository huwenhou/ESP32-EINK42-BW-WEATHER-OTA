三步完成

  1. 连接驱动板

    用数据线把 ESP32 驱动板接到电脑，确认线材支持数据传输。

  2. 安装固件

    点击上方按钮，选择驱动板对应的串口，确认安装，约 1 分钟完成。

  3. 连接 Wi-Fi

    手机连接热点 Robbie's Weather Board，在弹出页面选择 Wi-Fi 并输入密码。

常见问题

选择串口时列表是空的

多数是缺少 USB 转串口驱动。按驱动板上的芯片型号安装： CP210x 驱动 或 CH340 驱动，装好后重新插拔。

也可能是数据线只能充电，换一根数据线再试。

安装过程中连接失败

按住驱动板上的 BOOT 键不放，再点击安装，看到进度开始后松开。

想更换 Wi-Fi

设备正常运行时长按 BOOT 键 5 秒，会清除已保存的 Wi-Fi 并重新进入配网。不要在按 RST 的同时按 BOOT，那样会进入下载模式。

屏幕不刷新或花屏

开机画面左下角会显示识别到的屏幕驱动（UC8176 或 SSD1683）。拍下屏幕反馈即可，可通过固件强制切换驱动。

安装后还需要电脑吗

不需要。之后的更新会通过 Wi-Fi 自动下载安装，右上角版本号即当前最新固件。
